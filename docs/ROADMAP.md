# Roadmap

Runline is focused on becoming the cleanest iOS client for Cursor Cloud Agents.

## Cloud Agent Experience

- Keep the chat view message-first and easy to scan.
- Improve run event grouping as Cursor adds richer event payloads.
- Expand attachment handling where the Cursor Cloud API supports it.
- Add stronger artifact previews for screenshots, videos, logs, and generated files.
- Improve release-readiness and review prompt starters for one-off Cloud Agent launches.

## Navigation and UX

- Keep iPhone navigation tab-based and iPad navigation split-view based.
- Make repository selection, search, and chat continuation fast enough for repeated daily use.
- Keep Settings focused on account, appearance, notifications, and advanced API diagnostics.
- Preserve system, light, and dark appearance behavior.

## Not Planned

- A required hosted Runline backend.
- Storing user Cursor API keys outside the device.
- Shipping private maintainer release configuration in the public repository.
- Linking users to login-dependent Cursor web surfaces from the native app.
